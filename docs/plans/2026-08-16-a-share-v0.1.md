# A 股投研助手 v0.1 实施计划

## 目标

在 `a_share_research/` 内交付一个可独立运行、可审计、无券商能力的 A 股题材研究引擎，并通过独立的 DeepSeek Harness 插件暴露两个只读工作流工具。

## 已知现状

- 当前目录是一个尚无提交的新 Git 仓库，工作分支为 `feat/a-share-research-v0`。
- A 股与美股已有演示骨架；本轮只修改 A 股主路径，美股项目保持不变。
- 若干 `*nmkdir`、`*_junk`、`*_old` 和 `_legacy_copy_from_init` 路径是既有残留，本轮不删除、不改写。
- 远程 Mac `maol@100.88.153.6` 为 Intel macOS，已安装 Python、uv、Node、pnpm 和 DeepSeek Harness `0.1.0-rc.6`。
- 远程 `~/ai/stock` 已有课程、WORKFLOW、prompts、数据和历史报告；部署必须增量同步，禁止 `--delete`。

## v0.1 范围

1. 版本化 JSON 请求、Snapshot、ResearchPacket、ArtifactResult 合约。
2. 显式 demo fixture 与 snapshot-file 输入；不得把 fixture 标成真实数据。
3. 确定性时间校验、证据门槛、题材五维分析、候选分类与排除日志。
4. SQLite 运行、候选决策和 artifact 索引。
5. Markdown 与 JSON 报告，固定免责声明。
6. CLI：`init`、`doctor`、`run`、`artifact-read`。
7. DeepSeek Harness 原生 Cordis 插件：`cn_research_run`、`cn_artifact_read`。
8. 本机单元/契约/E2E 测试与远程 DSH 加载、工具调用测试。

## 非目标

- 不接券商、不下单、不生成价格目标或仓位建议。
- 不在 v0.1 抓取全市场实时数据。
- 不把 DSH session、profile 或 jobs 当研究数据库、隔离边界或定时器。
- 不让 Python 与 DSH 同时改写同一份正式报告；v0.1 正式 artifact 由 Python 引擎唯一生成。
- 不复制或公开课程原始内容；只保存方法卡和来源 manifest。

## 稳定接口

插件只通过 JSON stdin/stdout 调用：

```text
python -m a_share_research.cli run --request-json -
python -m a_share_research.cli artifact-read --request-json -
```

`market` 由引擎和插件硬编码为 `CN`，模型不能传入。工具结果只返回 `run_id`、`artifact_id`、状态、短摘要、缺口与相对 artifact 路径。

## 验收

1. 同一 fixture 与 `decision_at` 产生稳定的研究结果和 manifest hash。
2. 晚于 `decision_at` 的证据被拒绝或降级，并在报告中明确列出。
3. “观察”候选同时具备官方事件证据、同期结构化市场证据、传导链、下一催化、反方解释与证伪条件。
4. 报告只出现“排除 / 继续研究 / 观察”。
5. DSH 停止时 CLI 仍完整运行。
6. A 股工具没有 `market` 参数，插件不会访问 SQLite、数据商或券商。
7. DSH session 可见结果不含凭据、绝对路径和原始受限数据。
8. 远程 fixture run 与 DSH headless 工具调用均成功。
