我已经有投研 harness。你不是来重新搭建框架，也不是另写一篇投研方法建议。请在当前真实仓库中完成：现状审计 → 需求/经验接入 → 最小增量实现 → 回归测试 → 单次旁路演练 → 提交接管验收结果。

先读取同目录的 `01_REPORT_CONTRACT.md`、`02_LESSONS_AND_TESTS.md`、`03_ACCEPTANCE_AND_CUTOVER.md` 和 README。不要假设自己能自动访问我的 ChatGPT 云端历史。只使用实际可读取的文件/工具；缺失原始聊天不阻止需求迁移，但不得假装历史事实已经核验。

## 本次授权与禁止事项

本指令授权：在当前仓库读取资料；创建独立本地分支（遵守仓库规范）；在不覆盖未提交工作前提下进行与接管直接相关的最小代码/文档修改；运行现有测试；使用已经授权、预算明确的数据/模型能力做一次有限旁路演练。

不授权：push/创建或合并远程PR、生产部署、启用或停用定时任务、修改旧云端任务、付费开通数据源、突破现有预算、公开发布资料、接券商账户、操作交易系统、下单或自动调整仓位。仓库已有更严格审批规则时仍遵守。真实权限或预算缺失时完成不受影响部分，把剩余事项合并成一张决策卡，不循环询问、不假装成功。

日常运行不得自行修改程序、方法权重、指标定义、批准后的规则或测试基线。本次建设权限不能自动延续到每天的研究任务。

## 第一阶段：先查真实实现，不按记忆虚构接口

读取 AGENTS.md/override、README、架构说明、方法卡、项目配置、CLI帮助、workflow、数据adapter、PIT门槛、schema、模型配置、测试、快照存储、日志、调度与报告交付接口。检查 git status，不覆盖我的改动。不要扫描无关目录、打印密钥或读取无关个人资料。

把下列能力逐项标为“已实现且验证／部分实现／没有／无法核实”，附真实文件位置、入口和验证结果：
- A股日线、分钟/竞价数据及历史指标；海外同行行情、公告和事件日历。
- 在线采集与离线研究分离；时间边界；A股/美股隔离。
- 主题发现、方法评分、反方审查、报告渲染。
- 盘前预测保存与收盘按同一ID回填；日期索引和版本。
- 调度、主机可用性、认证/额度、去重、重试、告警和私人报告交付。

先形成能力矩阵和最小变更清单，再按清单实施。已有能力只接线，不重写。不存在的CLI和配置字段不能凭空声称已运行。若当前目录不是正确仓库，停止代码修改，清楚报告定位缺口。

## 第二阶段：把云端经验变成可读取的项目资产

复用已有规范/记忆/案例目录。只在必要时新增文件。让现有 AGENTS.md 增加一个简短的研究入口和读取顺序，不整份覆盖，也不把所有历史报告塞进全局指令。

持久化三层：
1. 稳定合同：数据真实性、截止时间、市场隔离、计算分工、研究边界、报告要求。
2. 经验登记：区分流程修复、待验证市场假设、反例、已撤销假设；记录版本、依据和适用条件。
3. 每日状态：冻结候选/备选、未解决问题、确认/失效条件、收盘结果和下一步。

云端市场案例全部先标“待核验历史材料”。不把过去模型的自我解释当事实。光通信案例要检验海外同行覆盖、光互联与6G区分、主线与买点分离；不能写成“以后必须看多CPO”。

## 第三阶段：只补最小闭环

默认运行目标：每日北京时间07:00触发盘前报告流程，数据截止不晚于07:00。实际开始、输入冻结、预测锁定、生成、发布分别记录，不能把07:08生成写成07:00已送达。若需要07:00准点送达，提出提前采集/冻结方案及数据时效代价，未经批准不宣称同时做到覆盖至07:00与07:00瞬时交付。

优先复用已存在的数据包、runner、schema、artifact-read和调度器。流程是：
已授权采集 → 截止时点数据包 → 程序计算 → 离线候选/反方审查 → 程序校验 → 冻结预测并回读 → 发布 → 收盘读取同一预测ID追加结果。

保留现有业务决策枚举；研究展示标签不能扩展交易权限。模型不能绕过harness直接计算行情、修改已冻结预测、任意联网加入截止后的消息或在日常运行中改生产代码。

结构化记录覆盖：运行ID与业务日期、实际时间、数据/方法/提示词版本、模型请求值与可核验返回值、主题/标的/备选、证据ID、基准、主线优先级、观察动作、确认/失效条件、质量缺口、review结果与发布回执。复用既有字段；新增字段先做兼容映射。

修复交接优先于扩接大量新信息源。不要新造平台、向量库、分布式队列或新的美股选股系统。

## 第四阶段：验收与旁路演练

按03文档测试：未来信息、缺失行情、失败引用、错误映射、旧闻/新催化、历史重建、分钟数据缺失、保存失败、重复触发、时区/休市、模型权限、外部页面指令注入、旧任务重复发布。

所有mock均标fixture；使用今天晚些时候才拿到的数据回放早报，只能标重建/演练，不得进入正式07:00样本。

先做一次不发布到生产的旁路闭环，产出真实可打开的证据包、报告、manifest和回读结果；若缺少模型/数据权限，给出测试通过与真实接入未完成的边界，不能使用假行情凑齐。

不要只说“已完成”。给出：
1. 真实仓库能力矩阵与复用/修改清单。
