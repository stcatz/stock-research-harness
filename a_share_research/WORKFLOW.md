# DeepSeek Harness A股题材研究工作流

## 1. 正确定位

不要让模型直接“预测近期会涨的股票”。更可靠的定位是：

> 用确定性工具寻找近期出现变化的题材和标的，再让模型整理证据、发现矛盾、建立受益链，最后由人决定是否继续研究。

课程解决“研究什么”，Harness 解决“如何分工、留痕、复核和重复执行”。

## 2. 系统分工

### 由脚本和数据工具完成

- 下载、去重、时间戳和来源留存
- 行情、成交量、相对强弱、板块宽度等计算
- 公告和政策关键词初筛
- 排除停牌、风险警示、流动性不足和数据缺失标的
- 将每次运行的输入保存成不可变快照

### 由 DeepSeek Harness 完成

- 将新信息归类为政策、主线分支、突发、景气、对标等题材
- 按“大、新、多、久、准”逐项分析
- 画出产业与利润传导链
- 区分核心、中军、弹性和边缘映射
- 对照行情寻找市场确认或反证
- 生成反方论证、证伪条件和后续催化日历
- 汇总成供人工复核的研究报告

### 必须由人完成

- 复核关键公告、数字和公司业务纯度
- 判断信息是否已经充分定价
- 决定是否进入纸面观察或真实交易
- 确定个人风险预算、仓位和退出纪律

## 3. 数据源优先级

一级事实源优先：

- 中国政府网政策文件库：`https://sousuo.www.gov.cn/zcwjk/`
- 巨潮资讯最新公告：`https://www.cninfo.com.cn/new/commonUrl?url=disclosure/list/notice`
- 上交所公告：`https://www.sse.com.cn/disclosure/listedinfo/announcement/`
- 深交所公告：`https://www.szse.cn/disclosure/listed/notice/index.html`
- 北交所公告：`https://www.bse.cn/disclosure/announcement.html`
- 公司官网、年报、招股书及监管问询回复

行情和行业数据应使用有明确许可、时间戳和复权说明的数据源。当前 collector 支持 BaoStock 日线，以及显式 opt-in 的 HiThink Financial API 日线、全市场宽度、特色池、估值与年度三表。两者都缺少公开的不可变 first-seen/vintage 契约，因此只能标为 `RECONSTRUCTED_NON_PIT`；HiThink 的供应商原因标签和结构化财务数据也不能替代公告原文。论坛、社交媒体、新闻摘要只做线索，不做最终事实依据。

外部 provider 必须经过以下边界后才能进入研究：

1. 只允许显式 collector 联网，DSH 和 `run` 不得直连数据商。
2. 先保存仓库外的私有原始响应与哈希，再标准化成 snapshot；snapshot 不携带响应正文或凭据。
3. 以真实响应完成时间作为 `retrieved_at/available_at`，不得使用请求前时间或人工回填时间。
4. 日线不复权；缺少除权参考价时 `preclose/pct_chg` 保持 `UNKNOWN`，不得由相邻未复权收盘伪造。
5. 财务三表只能按相同 `period_end` 对齐，空值保留 `UNKNOWN`；最新估值不能用于历史估值回放。
6. provider 数据只算 `structured_market`，最终候选仍必须具有独立的官方/一级证据。

## 4. 每日流程

### A. 盘前：发现变化

1. 收集上一交易日收盘后至当前的政策、公告、产品价格、订单和行业事件。
2. 只保留能影响业绩、估值或近期市场预期的信息。
3. 给每条信息标注发布时间、抓取时间、原文链接和潜在受益方向。

产出：`data/normalized/YYYY-MM-DD/events.jsonl`

### B. 初筛：题材资格与候选机会合同

逐项判断：

- 大：市场空间和潜在资金容量是否足够？
- 新：相对市场原有预期，新增变量是什么？
- 多：能否形成多个标的和清晰梯队？
- 久：是否存在后续催化，还是一次性消息？
- 准：催化是否发生在当前，是否契合市场环境？

任一题材若没有原始来源、明确受益路径或证伪条件，只能进入“待核实”，不能进入候选池。

五维是题材资格，不是候选结论。每个候选还必须分别回答：新增了什么信息、相对公司收入/利润/
现金流的经济量级、相对哪一个旧基线存在预期差、同期结构化行情显示何种定价状态，以及下一个可
正式核验的催化。经济影响的金额、分母、公式和 ratio 必须来自冻结的公司公告正文或同等一级内容；
摘要和媒体转述只能形成采集请求，不能获得经济量级分。

### C. 受益链映射

为每个候选回答：

1. 变化首先影响哪个产品、价格、需求、成本或政策约束？
2. 影响如何传导到收入、毛利、产能利用率或估值？
3. 哪些上市公司业务最纯，哪些只是概念映射？
4. 哪个可能是容量中军，哪个可能有弹性？
5. 公司公告是否支持这种受益关系？

每条候选传导链至少三环，并逐环标记 `supported` / `partial` / `unknown` / `contradicted` 与证据 ID。
主题级通用链不能替代候选级收入、成本、利润或现金流落点。

### D. 市场确认

只使用同一时点可获得的数据，检查：

- 板块是否不是单票独涨
- 核心标的相对强弱和成交量是否改善
- 是否出现梯队和扩散
- 当前处于启动、发酵、高潮、分化还是退潮
- 走势是否与利好程度相符；“该强不强”视为反证

行情确认不能替代基本面证据，也不能因为上涨而反向编造原因。

### E. 独立风险审查

canonical 引擎先生成不含 thesis、原反方和最终裁决的 `fact_packet.json`。联网 Harness 的独立反方只能
分页读取这个 `facts` 区段，先输出结构化 JSON；第二个裁判调用才可看到原报告。反方证据必须带 URL、
发布时间、可用时间和检索时间，网页中的指令一律作为不可信文本。没有独立调用时，报告中的
`falsification_contract.status` 保持 `pending_independent_review`，不能把同一次生成中的反方栏位冒充
独立证伪。

对每个候选强制生成反方报告：

- 催化是否已被价格反映？
- 是否只有口号，没有收入或利润贡献？
- 是否存在减持、解禁、监管问询、业绩恶化或流动性风险？
- 题材是否已进入一致高潮？
- 哪个事实出现后必须撤销研究结论？

### F. 每日报告

只输出三类结果：

- `排除`：出现明确负向证据、题材退潮、硬风险或经过老化复核后正式关闭
- `继续研究`：逻辑存在，但仍有关键事实待核实
- `观察`：新信息、经济量级、预期差、候选传导链和市场证据已达到确定性门槛，等待人工判断

普通数据缺口不会自动把所有候选吸入 `continue_research`。系统另外输出 `deep_dive` / `monitor` /
`backlog` / `closed` 注意力层；连续 14 天无状态、缺口或合格证据进展时降级复核，30 天时进入关闭
复核，但老化层本身不得篡改历史 canonical 状态。

禁止输出自动买卖指令。

## 5. 报告最低门槛

每个进入“观察”的候选必须同时具备：

1. 一条带时间戳的官方事件或公告证据
2. 一条同期结构化行情或行业数据证据
3. 至少三环、逐环绑定证据的候选级受益传导链
4. 尚未充分定价的具体理由，而不是主观感觉
5. 下一催化日期或观察窗口
6. 明确的证伪条件和主要风险
7. 至少一个反方解释

## 6. 验证这套方法是否真的有效

先运行纸面跟踪，不直接扩大真实资金：

1. 每天冻结当日输入与输出，禁止事后改写。
2. 分别统计政策、涨价、主线分支、突发和对标模式。
3. 以中证 800（`000906.SH`）为固定基准，由冻结快照自动结算精确第 5/20 个交易日的候选收益、
   基准收益和超额收益。
4. 同时统计被排除样本，避免幸存者偏差。
5. 至少积累 30 至 50 个同类样本，再判断某一模式是否有正期望。

评分只用于排序研究优先级，不代表上涨概率。

outcome 进入独立 append-only sidecar，绝不改写原 run。已从当日 seed 删除但 T+20 尚未到期的候选会
在 90 天只读 watchlist 内继续采集。汇总和 Harness 记忆必须按
`available_at <= evaluation_at` 过滤；缺少到期观察时维持 `UNKNOWN/incomplete`。当前合约只衡量三种
研究状态是否有区分度，不把结果包装成交易信号。最大不利/有利波动和 regime 分层尚未进入正式合约。

## 7. 自动化边界

DeepSeek Harness 官方支持 Web 工作区和一次性 `headless` 任务；定时运行由 `launchd` 或其他外部
调度器调用 `scripts/run_cn_harness_daily.sh`。该 wrapper 依次完成 snapshot 冻结、canonical run、跨快照
drift audit、事实盲审反方和最终机会备忘录。联网发现的新线索不会自动进入 seed；必须先由 collector
支持的正式来源核验并冻结。没有明确数据许可和人工复核时不得部署相应抓取，更不能连接券商交易接口。
