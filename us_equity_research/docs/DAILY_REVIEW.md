# 美股日报能力审计与运行方式（2026-09-13）

最新补充：日历刷新、TTM来源链、时点组件与追加式账本已进一步实现，见 [缺口优化结果](GAP_OPTIMIZATION.md)。下文保留初次审计范围。

## 审计结论

接通富途只解决结构化日线读取，不等于完成投研。原流程的断点是：临时 MCP 联调与固定 CLI 分离，行情只能单独生成附页；公司数据未配置日常刷新；仅三只样本不足以比较行业。原有严格证据时间门槛是正确的约束，不能通过填写虚假的发布时间来消除缺口。

本次新增：

- `FutuMCPTransport`：仅允许历史日线和美国交易日历；拒绝重定向；凭据只在内存中使用；限速错误最多重试三次，错误消息不带原始响应。
- `collect-futu-quotes --transport mcp`：读取 `FUTU_MCP_ACCESS_TOKEN`，与 REST 凭据分开。REST 原有默认行为不变。
- `daily-review`：从冻结行情、审核日历和独立 SEC 快照生成研究日报、计算包、冻结输入与哈希清单。
- `verify-daily-review`：不仅检查文件哈希，还用冻结输入重算指标和报告，检查研究截止时间和状态。
- `scripts/run_us_daily.py`：连接行情采集、SEC 刷新、日报写入和完整性验证。`--codex-mcp-auth` 明确选择宿主管理的 futu-quotes，只接受 quote:read；不把该令牌转发 REST。
- 行业比较覆盖 11 个 Select Sector ETF，并加入 SPY、QQQ、RSP、IWM 与研究对象 MSFT。只能观察 ETF 价格代理，不能称为全市场广度或自动选出个股龙头。
- SEC 联系标识已配置到本机忽略目录，仅供请求使用，不写入报告。新快照采集成功；原始主研究引擎也已按新 SEC 快照运行，结果仍为 MSFT exclude。

## 缺失功能与解决顺序

| 优先级 | 剩余缺口 | 可行解决方案与验收 |
|---|---|---|
| P0 | 正式行情时间语义 | 核供应商发布时间、数据有效时点、常规收盘 as_of 与授权口径；缺失则保留 UNKNOWN，不把日线日期当发布时间；当前日报明确降级 |
| P0 | 日历自动更新 | 从 NYSE/Nasdaq 公告生成带版本日历，与富途交易日核对；涵盖早收盘、临时休市及夏令时；当前显式审核日历只覆盖到 2026-09-14，过期必须更新 |
| P1 | 财报正文与经营指标 | SEC/IR 原始正文按段落提取，事实关联来源、期间和时间；人工复核收入驱动、云业务、资本开支与管理层指引。companyfacts 不等于已读正文 |
| P1 | TTM、时点股数、债务 | 同概念、同单位、同会计口径搭建 FY+本期YTD-去年YTD；分离加权平均股数和期末股数；债务组件去重并检查商业票据、短债遗漏 |
| P1 | 一致预期与超预期判断 | 选择许可明确的收入/EPS预期源，保存预测期间、样本口径和采集版本；未来持续积累公告前版本，不能用今天共识回填过去 |
| P1 | 已确认催化日历 | 公司 IR 公告优先，记录时区与修改历史；取消用研究种子日期冒充官方财报日。现有旧主引擎仍要求日期字段，日报将其标为未知 |
| P2 | 广度、波动率、个股领涨集 | 扩展经审核的成分股集合及 VIX/利率来源；验证停牌、退市与幸存者偏差；行业ETF排名不替代成分股参与度 |
| P2 | 盘中检查 | 另核实时/延迟权益、时段与频率，接入快照后才能执行开盘确认；目前只是人工检查计划，没有持续监控 |
| P2 | 复盘与标准校准 | 建立追加式计划—观察—证伪结果记录；区分阈值定义与实证效果，累计样本后评估误报、漏报和数据覆盖，不以单日报告证明策略有效 |

这些缺口并非都能靠提示词修复。数据语义、来源授权和真实历史版本要在采集层解决；TTM和估值要在计算层解决；计划兑现与阈值有效性要在复盘层解决。当前不需要为了补数据安装交易或账户插件。

## 日常入口

必须使用 US 项目 Python，先准备覆盖研究窗口与下一交易日的审核日历，以及冻结标的、基准和起止日期的行情计划。启动例子：

```sh
us_equity_research/.venv/bin/python scripts/run_us_daily.py \
  --root "$PWD" \
  --plan-json QUOTE_PLAN.json \
  --calendar-json REVIEWED_CALENDAR.json \
  --seed-json SEC_SEED.json \
  --run-id NEW_IMMUTABLE_ID \
  --codex-mcp-auth
```

OAuth 过期时明确失败，需要重新通过官方 quote:read 登录。没有悄悄扩大权限或切换到其他数据源。计划和日历日期不能直接沿用到无限未来；不声称已经安装自动调度。

显式 `--quotes-json` 可以复用已采集的冻结行情，但必须与计划完全一致，并保留原采集时间。用于离线复算和减少同日重复请求，不是假刷新。SEC 更新失败时报告显示公司证据缺失，不回退到未标识的旧数据。

```sh
us_equity_research/.venv/bin/python -m us_equity_research.cli \
  verify-daily-review --output-dir artifacts/us/daily_reviews/RUN_ID
```

日报输出归独立 US Python 写入，状态固定为 `DEGRADED_RESEARCH_ONLY`；主研究引擎的 Evidence→Claim→Thesis 门槛不变，正式候选未被旁路升级。原有 DSH 调用继续使用主研究引擎接口，新增日报目前由本地入口运行。

## 本次验证

- 实际读取 16 个标的各 72 个完整交易日、未复权与复权两套日线；日期集合与审核日历一致。
- 实际 SEC 刷新获得微软 10-K、8-K 证据及 5 条可提取财务事实；年度计算可用不表示 TTM/估值完整。
- Python 全套 119 项测试通过，新增覆盖缺失窗口、未来输入、重复日期、过期日历、产物篡改、不可覆写、只读白名单及限速重试。
- 日报可以从冻结输入离线重算；主研究产物另行验证，不改写旧产物。
- `2026-09-13-v1` 为本次中间预览，最终交付位于 `us-20260913-daily-final`；不同报告版本不会被当前校验器冒充支持。

## 观察计划（2026-09-13，v6）

报告首页现在先给基于当前窗口的市场判断及逐对象观察卡，再展示能力审计和事实附录。每张卡包括问题、数值基线、确认条件、反证条件、对应研究动作、证据索引和缺口；行业顺位由二十日相对表现产生，不能解读为交易推荐。公司种子仍受正式证据门槛约束。

下一完整交易日收盘更新基线；连续两次收盘规则从计划创建之后开始计数，不能由既有历史或一次盘中变化预填。两次收盘、多数行业阈值是未回测的研究约定，不报告胜率。分时不可用时写 UNKNOWN。计划全文随日常入口写入追加台账，后续结果必须引用对应计划。

本次使用 v5 相同冻结输入重新生成 v6 观察计划版，研究截止与行情时间未改称新采集时间。139 项单元测试通过，新旧报告离线复算通过。
